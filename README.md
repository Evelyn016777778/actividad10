# Sistema de Gestión de Cursos y Estudiantes en PHP

Proyecto desarrollado para aplicar Programación Orientada a Objetos (POO) en PHP y su persistencia en bases de datos MySQL.

## Instrucciones de Ejecución
1. Configurar un servidor local (como XAMPP o Docker) con soporte para PHP y MySQL.
2. Crear la base de datos ejecutando el script SQL proporcionado (`sistema_cursos`).
3. Clonar o descargar el repositorio en la carpeta raíz del servidor web (`htdocs` o equivalente).
4. Abrir el archivo `index.php` o `persistencia.php` desde el navegador.
